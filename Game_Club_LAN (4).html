Game Club community

Friends

Add players, chat with friends, and invite them to games.

Connecting to the online lobby…
Community lobby: Game Club connects through the same PeerJS service that chess game codes use, so it keeps working on networks that block other servers. One open Game Club tab acts as the lobby host; if that tab closes, another one takes over within a few seconds. Names, friend requests and chat messages are not private or encrypted. Avoid personal information.

Friend code

Works even when the lobby does not. Share your code, or type a friend's code to send them a request. You both need Game Club open.

Join a game

Enter the one game code shared by the player who created the room.

The host must have the room open while you join. The code is all you need to share.

Both players should be on the same Wi-Fi or wired network. A small online signalling service matches the code; chess moves are then sent directly between the two browsers.
